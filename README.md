One Emoji, One Dream Vacation — 🌅, sunrise over the sea: the first morning of the trip, dawn breaking over water you do not have to leave. A single emoji, nothing else, written by a stdlib-only Python program that enforces the one-emoji rule in code (exactly one emoji character, validated and round-trip verified) before writing it to `entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

The program writes exactly one emoji — 🌅 (U+1F305) — to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) and prints it.
